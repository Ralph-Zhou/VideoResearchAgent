# VideoResearchAgent training backend

This directory contains the project's customized verl runtime and video simulator.
The upstream runtime is retained as a dependency to preserve its dynamic imports,
Hydra configurations, model implementations, and tool/reward interfaces. Unrelated
examples, project reports, deployment images, and developer documentation are omitted.

See [training instructions](../docs/training.md) and the
[simulator instructions](video_search_sim/README.md).

The upstream Apache-2.0 [license](LICENSE), [notice](Notice.txt), and source
copyright notices are preserved. This is a project snapshot, not a declaration
that any arbitrary upstream verl version is interchangeable with this fork.
